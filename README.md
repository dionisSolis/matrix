## Описание

Библиотека `s21_matrix` предоставляет набор функций для выполнения основных операций над матрицами:

- Создание и удаление матриц
- Сравнение матриц
- Сложение и вычитание
- Умножение матрицы на число и на матрицу
- Транспонирование
- Вычисление определителя
- Вычисление матрицы алгебраических дополнений
- Нахождение обратной матрицы

Точность вычислений с дробной частью — до 6 знаков после запятой.

## Структура матрицы

```c
typedef struct matrix_struct {
    double** matrix;
    int rows;
    int columns;
} s21_matrix;
```

## Коды возврата

| Код | Значение |
|-----|----------|
| `0` | OK — операция выполнена успешно |
| `1` | Ошибка: некорректная матрица |
| `2` | Ошибка вычисления (несовпадающие размеры, невозможность вычисления и т. д.) |

Для функции сравнения используются макросы:

```c
#define SUCCESS 1
#define FAILURE 0
```
## Функции библиотеки

### Создание и очистка

```c
int s21_create_matrix(int rows, int columns, s21_matrix *result);
void s21_remove_matrix(s21_matrix *A);
```
- `s21_create_matrix` — выделяет память под матрицу заданного размера.
- `s21_remove_matrix` — освобождает память, занятую матрицей.

### Сравнение

```c
int s21_eq_matrix(s21_matrix *A, s21_matrix *B);
Возвращает `SUCCESS`, если матрицы совпадают по размерам и элементам (с точностью до 6 знаков после запятой), иначе — `FAILURE`.
```
### Арифметические операции

```c
int s21_sum_matrix(s21_matrix *A, s21_matrix *B, s21_matrix *result);
int s21_sub_matrix(s21_matrix *A, s21_matrix *B, s21_matrix *result);
int s21_mult_number(s21_matrix *A, double number, s21_matrix *result);
int s21_mult_matrix(s21_matrix *A, s21_matrix *B, s21_matrix *result);
```
### Транспонирование

```c
int s21_transpose(s21_matrix *A, s21_matrix *result);
```
Заменяет строки матрицы её столбцами.

### Определитель и алгебраические дополнения

```c
int s21_determinant(s21_matrix *A, double *result);
int s21_calc_complements(s21_matrix *A, s21_matrix *result);
```
- `s21_determinant` — вычисляет определитель квадратной матрицы.
- `s21_calc_complements` — вычисляет матрицу алгебраических дополнений.

### Обратная матрица

```c
int s21_inverse_matrix(s21_matrix *A, s21_matrix *result);
```
Находит обратную матрицу по формуле `A⁻¹ = (1/|A|) × (A*)ᵀ`, где `A*` — матрица алгебраических дополнений. Возвращает ошибку, если определитель равен нулю.

## Сборка

Проект собирается с помощью `Makefile`. Доступные цели:

| Цель | Описание |
|------|----------|
| `all` | Сборка библиотеки и тестов |
| `s21_matrix.a` | Сборка статической библиотеки |
| `test` | Сборка и запуск unit-тестов |
| `gcov_report` | Генерация HTML-отчёта о покрытии кода тестами |
| `clean` | Удаление сгенерированных файлов |

Пример использования:

```bash
make            # собрать всё
make test       # запустить тесты
make gcov_report # сформировать отчёт о покрытии
make clean      # очистить артефакты сборки
```
## Тестирование

Unit-тесты написаны с использованием библиотеки **Check** и покрывают не менее 80% каждой функции. Для запуска:

```bash
make test
```
## Покрытие тестами

Для генерации HTML-отчёта о покрытии используется `gcov`:

```bash
make gcov_report
```
После выполнения отчёт будет доступен в виде HTML-страницы в директории проекта.

## Требования

- Компилятор `gcc`
- Стандарт языка C11
- Библиотека `Check` (для тестов)
- `gcov` и `lcov` (для отчёта о покрытии)
- Соответствие Google Style
